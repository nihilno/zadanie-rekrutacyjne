# Zadanie rekrutacyjne – aplikacja React + Vite

## Opis

Projekt frontendowy zbudowany w oparciu o React, TypeScript oraz Vite.

## Uruchomienie projektu

### Wymagania

Node.js >= 18 (zalecane: 20+)  
npm (lub yarn / pnpm)

### Instalacja

```bash
git clone https://github.com/nihilno/zadanie-rekrutacyjne.git
cd zadanie-rekrutacyjne
npm install
npm run dev
```
